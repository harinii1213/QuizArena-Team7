# QuizArena

## About
QuizArena is a simple quiz website where users can answer quizzes and view their scores.

## Features
- Multiple quiz questions
- Dark mode
- Leaderboard
- Responsive design
- Contact page

## Technologies Used
- HTML
- CSS
- JavaScript
